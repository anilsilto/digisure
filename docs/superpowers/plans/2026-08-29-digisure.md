# DigiSure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build DigiSure — a Laravel web app for Zafir Sigorta where visitors request insurance quotes online, agency staff enter competing offers from 4 insurers by hand, and customers compare offers, track policies, and get renewal reminders.

**Architecture:** One Laravel 11 application, three auth guards (public / `customer` via SMS OTP / `panel` via email+password). Quote engine talks to insurers through a `QuoteProvider` interface; v1 binds all four insurers to a `ManualProvider` that opens "pending" quote rows for staff to fill. Renewal reminders run off the Laravel scheduler + database queue. Products and their form fields are data (`product_types.field_schema` JSON), not code.

**Tech Stack:** Laravel 11, PHP 8.2+, MySQL/MariaDB, Blade + Tailwind CSS + Alpine.js, Pest for tests, Laragon for local dev, database queue driver, Netgsm HTTP SMS.

**Spec:** `docs/superpowers/specs/2026-08-29-digisure-design.md`

## Global Constraints

- **PHP** 8.2+; **Laravel** 11.x. No Redis — queue/cache/session on `database` or `file`.
- **Project name / identifiers:** `digisure` (composer name `zafir/digisure`, DB `digisure`, config file `config/digisure.php`, command namespace `digisure:*`).
- **Brand palette (Tailwind `theme.extend.colors`):** `navy` `#1B2E6E`, `navy-dark` `#1a2340`, `zred` `#C41E2A`, `zred-dark` `#a01820`, `zred-tint` `#FDF0F1`, `navy-tint` `#F4F6FB`, `navy-tint-2` `#EEF1F8`, `line` `#EAECF0`, `line-2` `#D6DCE8`, `ink` `#1a2340`, `muted` `#5a6a7a`, `gold` `#E8A020`, `ok` `#0F6E56`.
- **Language:** all UI copy, DB enum values, and route slugs in Turkish (no diacritics in enum values / slugs: `saglik`, `teklifler_hazir`). User-facing text may use full Turkish.
- **PII:** `customers.tc_no` and `customers.phone` stored with Laravel `encrypted` cast; every lookup uses a companion `tc_hash` / `phone_hash` column (HMAC-SHA256 keyed by `APP_KEY`). Never log raw TC/phone — mask as `123******89`.
- **Money:** `decimal(12,2)`, Turkish Lira, no currency conversion.
- **Slogan:** "Geleceğinizi Güvence Altına Alıyoruz". Licence line: "SEDDK lisanslı sigorta brokeri". Agency contact: `info@sigortacimzafir.com`, 0532 265 23 92, "Zübeyde Hanım Mah. Sebze Bahçeleri Cd. No:11, 06070 Altındağ / Ankara".
- **TDD:** every task starts with a failing test and ends with a commit. Conventional commit messages.
- **Scheduler cron (deploy doc only):** `* * * * * php artisan schedule:run`.
